\note{\textbf{The net-gain claim does not survive measurement, but something
sharper does.} By \code{rocq wc}, paco $\to$ old port is proof $-754$ lines, spec
$+333$, total $-421$, and $-18$ including comments. So the total did not rise; it
was a wash. Two replacements that the data does support, either of which is a
stronger sentence than the original: (1) tactic surface \emph{nearly tripled},
$4\,586 \to 12\,754$ characters, $+178\%$; (2) tactic definitions in

these files and its spec/proof split is wrong in both directions; see
\code{paper-data/rocqwc-unsound.md}. The figures quoted throughout this paper
come from the corrected classifier, not from \code{rocq wc}.}

We can see in \Cref{fig:loc} that nearly all of this stems from definitions. Why?

\note{\textbf{This part holds, and the mechanism is now precise.} Across
\code{theories/}~+~\code{extra/} the definition column rose $8\,853 \to 8\,934$
during the port, the only measure that rose at all. Separating tactic code out of
that column: ordinary definitions \emph{fell} $8\,726 \to 8\,574$, and tactic
lines rose $127 \to 360$. The $81$-line rise is $-152$ ordinary plus $+233$
tactic. Every bit of the definitional growth is tactic workaround code, which is
exactly the claim below.}

We identified two main reasons:
\begin{enumerate}
  \item Some simple bugs in the coinduction library required large workarounds to
        fix.
  \item The \code{step} tactic for exposing the \bfun{} was not expressive enough,
        requiring large redefinitions.
\end{enumerate}

Furthermore, the enhanced coinduction library contained a few technical warts
that made development slow. In particular, some of the error messages were quite
mysterious:
